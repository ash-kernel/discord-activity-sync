<p align="center">A highly configurable, feature-rich Discord RPC extension</p>

## ✨ Features

- **Workspace & Git**: Displays your active project and git branch.
- **Diagnostics**: Live error and warning count for your active workspace.
- **Smart Idle**: Automatically hides file details when you step away.
- **File Stats**: Displays your current file name, cursor position (`:ln:col`), and total lines.
- **Privacy First**: Fully configurable via VS Code settings. Turn off any feature you want!
- **Icons**: Simple monochrome-style icons
